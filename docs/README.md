# MAC Filter 판정 도구

이 리포지토리는 3x3, 5x5, 13x13, 25x25 등 다양한 크기의 필터와 패턴에 대해 MAC 연산으로 판정하고 성능을 측정하는 콘솔 기반 Python 애플리케이션을 포함합니다.

사용법

- 대화형 모드 (콘솔 입력):
  - `python3 main.py`
  - 두 개의 필터(A,B)와 패턴(3x3)을 각각 행 단위로 입력합니다.

- 배치 모드 (data.json 사용):
  - `python3 main.py --batch data.json`
  - `data.json` 파일에 정의된 필터들과 패턴들을 로드하여 일괄 판정합니다.

출력

- 각 케이스별로 선택된 필터(`cross` 또는 `x`), 연산 시간(평균 ms), 판정 결과와 기대값 비교(PASS/FAIL)를 출력합니다.
- 성능 분석은 크기별 평균 연산 시간(ms)과 측정 횟수를 제공합니다.
- 마지막에 전체 케이스 수, 통과/실패 수, 실패 케이스 목록을 출력합니다.

설계 및 한계

- MAC 연산은 단순히 요소별 곱의 합으로 구현되어 있습니다.
- 비교 정책은 절대 오차 기반이며, `eps=1e-6`를 사용합니다. 작은 부동소수점 차이는 `UNDECIDED` 또는 `FAIL`로 이어질 수 있습니다.
- 성능 측정은 Python의 `time.perf_counter()`를 사용하여 ms 단위 평균을 계산합니다. 반복 수는 크기에 따라 동적으로 설정됩니다.

실패 원인 분석 포인트

- 라벨/스키마: `data.json`의 expected 라벨('+','x')이 내부 네이밍(`cross`/`x`)과 매핑됩니다. 이 매핑 실패 시 오답이 발생할 수 있습니다.
- 부동소수점: 필터 값이 근사값일 때 정밀도 차이로 판정이 달라질 수 있습니다. 필요시 상대오차/절대오차 기준을 조정하세요.
- 비교 정책: 현재 절대 차이만 고려합니다. 둘 다 거의 같은 경우 중립 판정(`UNDECIDED`) 대신 다른 정책(예: 우선순위, 비율비교)을 적용할 수 있습니다.

시간 복잡도

- 한 번의 MAC 연산은 O(N^2) 요소 곱셈/덧셈을 수행합니다. 배치 모드에서 각 케이스는 두 필터와 비교하므로 O(2*N^2).
- 반복 측정을 포함하면 전체 시간은 반복 수 * O(N^2) 입니다.
